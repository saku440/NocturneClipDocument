はじめに

ダウンロードいただきありがとうございます。 初めて使う方は、「セットアップガイド」と「撮影ガイド」を順に読めば、すぐに撮影を始められます。

NocturneClip について

NocturneClip は、VRChat の純正カメラで撮影した写真に、レンズのようなボケ感を上乗せするアバター用ギミックです。 特にデスクトップモードでの撮影体験をより楽しくすることを目標に制作しました。

動作環境

  • PC 版 VRChat のデスクトップモード
  • Unity 2022.3.22f1
  • VRChat SDK（Avatars） 3.10.4
  • Modular Avatar 1.18.1 以上

VRChat SDK と Modular Avatar は、VCC または ALCOM でプロジェクトに追加してください。

セットアップガイド

  1. Modular Avatar を入れたプロジェクトに、NocturneClip のパッケージをインポートします。
  2. Unity の上部のメニューから「NocturneClip > セットアップ」を開きます。
  3. 「アバター」の欄に、シーンに置いたアバターを入れます。
  4. 「このアバターに入れる」を押すと、「NocturneClip」というオブジェクトがアバターに追加されます。
  5. アバターをアップロードします。

撮影ガイド

  1. エクスプレッションメニューの「NocturneClip」から「ON」を押します。
  2. 純正カメラを開き、フォーカス（絞りのアイコン）を「なし」にします。
  3. 撮りたい物を画面中央の枠に合わせると、自動でピントが合います。
  4. 左Shift＋F1〜F6 で F値を選びます。
  5. 純正カメラで撮影します。

画面の端にある物にピントを合わせたいとき

その物を画面中央の枠に置いて、左Shift＋F8 でピントを固定します。そのあとで構図を整えてください。

撮影上の注意

写真の解像度は 1080p 以上にしてください。720p にすると、F値などの表示が写真に写ってしまいます。

キー操作（左手のジェスチャー）

デスクトップモードでは、左Shift＋F1〜F8 は VRChat で左手の形を変えるキーです。NocturneClip は、この左手の形を合図にして動きます。

左Shift＋F3F値 3（最初は F2.8）
左Shift＋F4F値 4（最初は F4）
左Shift＋F5F値 5（最初は F5.6）
左Shift＋F6F値 6（最初は F8）
左Shift＋F7ピント固定を外す
左Shift＋F8ピントを固定する
← 表は横に動かせます
  • キーの番号と F値の数字は一致していません。どのキーにどの F値を入れるかは、セットアップ画面で変えられます。
  • 左手で何もしていないときは、左Shift＋F1 と同じ扱いになります。いちばんよく使う F値を F1 に入れておくのがおすすめです。
  • 写りごとに別の F値を入れている場合は、写りを切り替えると、同じキーでも F値が変わります。
  • ハンドジェスチャーで F値を変えているため、アバターの手、表情、耳などが動きます。自撮りが中心の方は、表情固定ギミックなどと併用してください。

自動ピント

画面の真ん中にある物に、ピントを合わせ続けます。

※ まつ毛や髪の毛先のような、細い物や小さい物には合いにくいことがあります。

ピント固定

左Shift＋F8 を押すと、そのときの純正カメラの位置と向きを覚えます。そこから覚えた向きに真っすぐ線を伸ばし、その線の上に見えている物にピントを合わせ続けます。 固定したあとにカメラの向きを変えても、ピントはその線の上の物に残ります。

固定は、特定の人や物を追いかける機能ではありません。次の点に気をつけてください。

  • 被写体が動いて線から外れると、ピントは線の上にある別の物（背景など）に移ります。動く被写体は、固定し直してください。
  • 線の手前を別の物が横切ると、ピントはその物に移ります。
  • 線の上の物が画面に写っていないときは、自動ピントに戻ります。また写れば、固定に戻ります。ただ、カメラを大きく動かしたときなどは、戻らないことがあります。そのときは左Shift＋F7 で固定を外して、もう一度固定してください。

固定は、左Shift＋F7 を押すか、NocturneClip を止めるまで続きます。F値を変えても、固定は外れません。

固定する物を変えたいときは、左Shift＋F7 で一度外してから、もう一度左Shift＋F8 を押してください。VRChat の仕組み上、F8 を続けて押しても 2 回目は届きません。

画面表示

純正カメラのプレビューに、次のものを表示します。

  • 上の段：F値／ピントの距離／焦点距離（mm）
  • その下：距離の目盛り。ピントが合う範囲を緑で示します。
  • 真ん中の枠：白はピントが自動で動いている状態、緑はピントを固定している状態です。

表示は、描く大きさが 1280×720 以下のときだけ出ます。そのため、写真の解像度を 720p にすると写真にも写ってしまいます。1080p 以上なら写りません。

更新ガイド

古い版を残したまま新しい版をインポートすると、エラーが出ることがあります。次の手順で入れ替えてください。

注意：「NocturneClip」フォルダを消すと、NocturneClip を入れたすべてのアバターの設定（F値など）も消えます。F値を変えていた場合は、消す前に控えておいてください。

  1. NocturneClip を入れたすべてのアバター（ほかのシーンにあるものも含めて）から、「NocturneClip」オブジェクトを消します。
  2. プロジェクトの「NocturneClip」フォルダを消します。
  3. 新しい版のパッケージをインポートします。
  4. NocturneClip を使うアバターごとに、セットアップ画面で「このアバターに入れる」を押します。
  5. それぞれのアバターをアップロードします。

アバターに入れたときに作られたデータも「NocturneClip」フォルダの中にあります。そのため、一部のアバターだけ入れ直すと、残りのアバターは正しく動きません。

手順 1 を忘れたアバターでも、入れるときに古い「NocturneClip」の壊れた残りが見つかれば、消すかどうかを聞く画面が出ます。

削除

  1. アバターの中の「NocturneClip」オブジェクトを消します。
  2. アバターをアップロードします。

ほかに NocturneClip を入れたアバターがなければ、プロジェクトの「NocturneClip」フォルダも消してかまいません。

注意事項

他のプレイヤーへの影響

  • NocturneClip が描くのは、自分の画面だけです。ほかのプレイヤーの画面には何も出ませんし、ほかのプレイヤーが撮る写真にも影響しません。
  • パラメータはどれも同期しません。
  • 左手の形はほかのプレイヤーにも見えます。 F値の切り替えやピントの固定には VRChat の左手のジェスチャーを使うので、手の形や、それに合わせて動く表情などは、いつもどおりほかの人にも見えます。

制限事項

写りについて

すぐ手前の物を大きくぼかす写真は苦手です
明るい背景に細い物（窓枠など）が重なる所で、ボケの縁が浮いて見えたり、後ろの物が途中で切れたり、手前の物の形が透けて見えたりします。手前の物に隠れた背景は写真に写っていないので、周りから推し量って埋めているためです。こういう写真では、純正のボケのほうが自然なこともあります。その場合は、エクスプレッションメニューの「ON」をもう一度押して NocturneClip を止め、純正カメラのフォーカスを元に戻してください。

半透明の物は、ボケ方が不自然になることがあります
髪の毛先やエフェクトなどの半透明の素材（レンダーキュー 2501 以上）は、距離の情報を持ちません。そのため、その後ろにある物の距離でぼかされてしまいます。純正のボケでも同じことが起きます。

アニメ調のアバターの輪郭線が残ることがあります
手前でボケても、細い線が残ることがあります。

画面表示について

ワールドの後処理で、表示が読みにくくなることがあります
色の調整や光のにじみなどのワールドの後処理は、NocturneClip の後にかかります。そのため、後処理の強いワールドでは、画面表示の色が変わったり、文字がぶれたりすることがあります。

純正カメラの「反転」で、表示が左右逆になります
アンカーが「デフォルト」以外のときに「反転」を使うと起きます。写真とボケには影響しません。

対象外

  • 動画（ストリームカメラなど）向けの作りにはなっていません。
  • VR では動作を確認していません。デスクトップモードで使ってください。
  • VRC+ のカメラドローンは対象外です。動作も確認していません。

困ったとき

よくある質問

ほかのプレイヤーに見えますか。

NocturneClip が描くものは見えません。ただし、操作に使う左手の形は見えます。くわしくは「他のプレイヤーへの影響」を参照してください。

重いですか。

カメラを開いた状態で大きくボケる構図を写していると、重くなります。重いと感じたときは、F値を大きくしてボケを小さくしてください。

VR で使えますか。

VR では動作を確認していません。デスクトップモードで使ってください。

純正カメラの「飛行モード」とカメラドローンは違うものですか。

違うものです。飛行モードは、純正カメラを手から離して動かす機能で、NocturneClip と一緒に使えます。カメラドローンは VRC+ の別の機能で、NocturneClip の対象外です。

純正カメラのフォーカスと一緒に使えますか。

一緒に使うとボケが二重にかかるので、純正カメラのフォーカス（絞りのアイコン）は「なし」にしてください。

ピントを固定して、動く人を追いかけられますか。

追いかけられません。固定は、覚えた向きの線の上に見える物にピントを合わせる機能です。被写体が動いたら、固定し直してください。

プレビューと写真で、ボケの大きさは同じですか。

同じです。写真の解像度が変わっても、写真全体に対するボケの大きさが同じになるように計算しています。

参考文献

ボケの作り方は、次の公開資料の考え方を参考にしました。

  • Jorge Jimenez「Next Generation Post Processing in Call of Duty: Advanced Warfare」SIGGRAPH 2014 — タイルで手前のボケが届く範囲を調べる方法、手前と奥を分けて集める方法、3x3 の真ん中の値を取るフィルタ、点ごとの回転に使うノイズ（Interleaved Gradient Noise） https://www.iryoku.com/next-generation-post-processing-in-call-of-duty-advanced-warfare/
  • Tiago Sousa「CryEngine 3 Graphics Gems」SIGGRAPH 2013 — 周りから集める方式のボケと、仕上げの真ん中の値を取るフィルタ
  • Guillaume Abadie「A Life of a Bokeh」SIGGRAPH 2018（Unreal Engine の被写界深度）— 手前と奥を別の層として扱う考え方 https://dev.epicgames.com/documentation/unreal-engine/cinematic-depth-of-field-in-unreal-engine
  • AMD FidelityFX Depth of Field — 手前の物の後ろを周りから埋める考え方 https://gpuopen.com/manuals/fidelityfx_sdk/techniques/depth-of-field/
  • Catlike Coding「Depth of Field」— 奥のボケを手前ににじませない考え方 https://catlikecoding.com/unity/tutorials/advanced-rendering/depth-of-field/
  • 薄レンズの式（ボケの大きさの計算）
